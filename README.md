# Cadastro de Carros

Projeto desenvolvido em Python para cadastrar e gerenciar veículos.

## Funcionalidades

- Cadastrar carros.
- Listar veículos cadastrados.
- Pesquisar carros pelo modelo.
- Excluir veículos.
- Gerar relatório do estoque.
- Identificar o carro mais caro e o mais barato.
- Salvar os dados em arquivo JSON.
- Validar os dados informados pelo usuário.

## Tecnologias utilizadas

- Python
- JSON
- Git e GitHub

## Como executar

1. Instale o Python.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

python main.py
